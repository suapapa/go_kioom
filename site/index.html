키움증권 REST API 명세에 맞춘 비공식 Golang 래퍼 패키지입니다. Go 클라이언트, CLI, MCP 서버가 한 저장소에 모여 있습니다.

시작하기 GitHub 저장소

MCP (kioom-mcp)

동일한 Client를 Model Context Protocol(MCP) 서버로 노출합니다. Cursor, Claude Desktop 같은 MCP 클라이언트는 stdio(기본)나 HTTP+SSE로 연결하면 키움 API를 다룰 수 있습니다.

CLI (kioom-cli)

JSON 입출력과 스키마 조회용 CLI입니다. 터미널에서 API를 테스트하거나 자동화 스크립트에 붙이기 좋습니다.

Go Package

Go에서 바로 쓸 수 있는 클라이언트 패키지입니다. 토큰 발급·갱신, 에러 처리, 요청·응답 구조체가 정리돼 있어 백엔드에 붙이기 편합니다.

사용 방법 (Go Package)

클라이언트를 만들고 계좌 정보와 주식 시세를 조회하는 예제입니다.

package main

import (
	"fmt"
	"log"
	"github.com/suapapa/go_kioom"
)

func main() {
	client := kioom.NewClient("YOUR_APP_KEY", "YOUR_SECRET_KEY", true)

	tokenRes, err := client.IssueToken()
	if err != nil {
		log.Fatalf("토큰 발급 실패: %v", err)
	}
	
	acctRes, err := client.GetAccountNumber()
	if err != nil {
		log.Printf("계좌번호 조회 실패: %v", err)
	} else {
		fmt.Printf("계좌번호: %s\n", acctRes.AcctNo)
	}
}
